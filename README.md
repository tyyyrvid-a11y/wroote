# Wroote
Um aplicativo simples focado em escrever livros.

### Recursos
- Organização em capítulos
- Contador de palavras
- Contador de páginas
- Modo escuro
- Efeitos
- Escrita do núcleo (detalhes sobre o livro)

### Informações
Esse app foi escrito em dart (usando a framework flutter) e ele está disponível para Windows, Linux e MacOS.
